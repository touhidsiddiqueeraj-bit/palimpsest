Palimpsest

The Markdown editor with a memory. Your text is always a plain .md file. Your history — every automatic snapshot and every milestone you name — is stored locally in this browser's IndexedDB. Nothing is ever transmitted anywhere. Diffs are computed word-by-word, built for prose: rewrapping a paragraph doesn't explode the comparison.
